# 双行聊天框、模型服务显示与误触修复总结 (Walkthrough)

## 1. 核心改进清单

### 1.1 聊天框升级为双行高度并在右侧显示当前模型服务
- **双行输入框**：输入框采用 `axis: .vertical` 与 `lineLimit(2...3)` 双行高度，更宽敞舒适；
- **当前模型服务徽标**：在输入框右侧状态栏实时显示当前使用的 AI 服务名称与模型（例如 `⚡️ agy · gemini-3.7-flash` 或 `⚡️ OpenAI · gpt-4o`），支持点击一键快速跳转至模型配置页面。

### 1.2 修复误触推荐胶囊直接发送指令的问题
- **原因剖析**：之前点击主界面下方的「智能推荐 Skill 胶囊」时，直接触发了 `submitInstruction`，导致误触时直接创建了任务；
- **修复措施**：点击推荐 Skill 胶囊改为 **仅将指令填入输入框（填充文本）**，由用户确认后自行发送，避免误触直接执行。

### 1.3 悬挂与孤儿任务状态清理
- 冷启动时将未完成的悬挂任务自动标记为已中断；
- 用户在 Diff 预览页点击取消时，自动同步取消关联的任务，不再常驻卡在「进行中」。
