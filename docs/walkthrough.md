# 全链路实时秒表计时与 Fast-Path 启发式极速分流总结 (Walkthrough)

## 1. 核心改进清单

### 1.1 慢速原因根因与极速分流方案 (Fast-Path Heuristic Engine)
- **原因根因**：
  - 当配置本地 CLI 引擎（如 `agy`、`claude`、`ollama`）或云端 API 时，`CLIModelClient` 会启动子进程并加载完整的上下文与系统提示词。对于 `agy` 这种全功能编码 Agent，每次冷启动初始化、工具挂载和多轮推理往往需要 **10 ~ 25 秒**；
- **极速分流方案**：
  - 在 `AgentDispatcher` 中集成本地 **Fast-Path 启发式极速引擎**。对于常见的明确意图（如 "转成 A3 横版 pdf"、"转成 pdf"、"统一改为 1920x1080"、"转为 png/jpg"、"批量重命名"），直接在 **0.01 秒 (10 毫秒)** 瞬时生成执行 Plan，无需等待大模型子进程；
  - 若输入较为复杂的模糊推理指令，则无缝交由大模型/CLI 规划，并施加 25 秒超时与进程保护。

### 1.2 全链路毫秒级与实时秒表计时
- **主浮窗实时秒表**：
  - 发送指令后，输入框右侧与状态栏实时显示动态秒表（如 `AI 正在分析意图并规划操作方案... (⏱️ 1.4s)`）；
- **任务看板缩略小卡片**：
  - 实时显示任务耗时（如 `✓ 产出 4 项 • ⏱️ 80ms`、`已完成 • ⏱️ 1.2s`、`进行中 • ⏱️ 3.4s`）；
- **任务详情弹窗**：
  - 顶部基本信息显示 `⏱️ 总耗时: 1.23 秒`；
  - 处于执行中时，实时滚动展示 `正在执行文件处理流程... (⏱️ 已耗时 2.5s)`；
  - 任务看板每秒自动同步刷新后台任务。
