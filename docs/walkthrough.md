# 结果文件一键定位、打开与高亮标签功能总结 (Walkthrough)

## 1. 核心改进清单

### 1.1 主面板「访达高亮定位横幅」与快捷操作 (`MainFloatingPanel.swift`)
- 任务执行成功后，主面板底部即刻弹出绿色定位横幅：
  - **`[🔍 在访达中高亮定位这 N 个生成文件]`**：点击后直接调用 macOS 原生 API `NSWorkspace.shared.activateFileViewerSelecting(urls)`，系统自动打开目标文件夹并将刚生成的文件一次性全部选中高亮；
  - **`[📂 打开目录]`**：直接打开产出文件所在的目标文件夹；
- 在主界面文件列表中：
  - 为刚生成的新文件打上醒目的 **`[✨ 刚生成]`** 绿色徽标；
  - 每一行文件均提供 **`[🔍 定位]`** 和 **`[▶️ 打开]`** 快捷按钮。

### 1.2 任务详情弹窗产出文件完整操作 (`TaskBoardView.swift`)
- 在任务详情弹窗「📂 执行结果与产出」区域：
  - 顶栏提供 **`[🔍 在访达中定位全部]`** 和 **`[📂 打开目录]`** 批量操作；
  - 每一条产出文件项展示完整路径，并附带 **`[🔍 定位]`**、**`[▶️ 打开]`**、**`[📋 复制路径]`** 独立操作按钮。
