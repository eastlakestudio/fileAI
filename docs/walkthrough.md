# 任务「再次执行」按钮与重跑链路总结 (Walkthrough)

## 1. 核心改进清单

### 1.1 缩略卡片「再次执行」快捷入口 (`taskCompactCard`)
- 任务列表中每个缩略小卡片右侧增加了 **`[🔄 再次执行]`** 独立快捷按钮；
- 点击后自动以该任务的 Prompt 返回主界面，结合当前选中的文件重新发起调度。

### 1.2 任务详情弹窗「再次执行此任务」(`TaskDetailSheet`)
- 任务执行详情弹窗顶部新增了高亮操作项 **`[⚡ 再次执行此任务]`**；
- 无论是过去已完成的任务，还是执行失败的任务，均可一键极速重试。

## 2. 自动化测试

- 新增 `TaskBoardRerunTests` 路由与 Prompt 回填测试，全量 **35 个单元测试全部通过（100% Pass, 0 failures）**。
