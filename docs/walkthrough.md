# 任务全生命周期持久化与 CLI 权限免拦截总结 (Walkthrough)

## 1. 问题与核心修复

### 1.1 修复任务未持久化至任务看板的问题
- **原机制漏洞**：原逻辑仅在物理操作规划成功且包含变更项时才创建 `TaskManager` 记录，如果规划阶段失败（如 CLI 报错）或用户只是做文件统计问答（无物理变更），任务记录未被创建；
- **全生命周期即时持久化**：
  1. **提交即创建**：用户一按回车/点击发送，系统立刻在 `TaskManager` 生成 `.inProgress` 记录并落盘；
  2. **规划失败**：自动更新为 `.failed` 并记录具体错误原因，持久化展示在看板「执行失败」Tab 中；
  3. **问答/统计**：自动更新为 `.completed` 并记录 AI 回复结果，持久化展示在看板「已完成」Tab 中；
  4. **物理文件操作**：执行完毕后自动更新为 `.completed` 并详细记录生成文件清单。

### 1.2 修复 `agy` 权限拦截报错 (`user denied permission`)
- 为 `CLIModelClient` 中 `antigravity` 的调用参数补齐 `--dangerously-skip-permissions`，免除无终端交互环境下的权限阻塞。
