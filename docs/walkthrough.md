# 文件魔法棒 (FileMagic Wand) 架构升级与发布总结 (Walkthrough)

## 1. 核心需求与改造清单

### 1.1 APP 名称与标题栏极简化
- **名称统一升级**：首页及各处窗口标题栏正式更名为 **「文件魔法棒」**；
- **顶栏空间释放**：移除标题栏冗长易挤压的路径胶囊，下沉至主内容区顶部面板，清晰展示当前操作路径与已选文件计数。

### 1.2 Skill 体系全面 Markdown 化与云端市场
- **独立 Markdown 驱动 (`SKILL.md`)**：每个技能均为独立的 `.md` 文件，包含标准 YAML Frontmatter 元数据与正文说明；
- **两栏导航模式**：左侧分类导航栏（全部技能、图片处理、文档与PDF、整理重命名、云端市场）+ 右侧技能卡片与市场列表；
- **云端扩展一键安装**：支持从云端预设库（视频压缩、OCR 提取、音频转写、表格互转）一键下载至本地，或通过粘贴 Markdown 源码直接导入自定义技能；
- **本地目录双向同步**：技能文件自动维护于 `~/Library/Application Support/AIFileAssistant/skills/*.md`，支持访达直接编辑与管理。
